# 📝 ToDo List — Simple and Clean Task Manager

A minimalist web application for adding and deleting tasks.
Built with pure HTML, CSS, and JavaScript — no frameworks, no libraries.

### 🌍 Live Demo

[Open on GitHub Pages](https://CallmeHelga.github.io/simple-todolist/)

### 🚀 Features

- Add tasks using a button or the Enter key
- Delete tasks individually
- Clean and responsive interface

### ⚙️ Technologies

- HTML5
- CSS3 (responsive layout)
- JavaScript (DOM manipulation, events)

### 📚 Planned Improvements

- Save tasks using localStorage
- Ability to mark tasks as "completed"
- Task filtering: all / active / completed
- Intro screen with `setTimeout()` animation
